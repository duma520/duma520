## 💾 自动备份机制（必须遵守）
每次执行 `README.md` 的更新操作前，必须强制执行以下备份步骤：
1. 检查当前目录下是否有 `version` 文件夹，若无则创建。
2. 获取当前时间戳（YYYYMMDD_HHMMSS）。
3. 将当前的 `README.md` 复制到 `version` 目录下，命名为 `README_YYYYMMDD_HHMMSS.md`。
4. **备份完成后，才能开始后续的比对和覆盖写入操作。**
